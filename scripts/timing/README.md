Timing scripts behind Table S3. They were run on a node with an AMD EPYC 7H12 and NVIDIA L40S GPUs;
paths assume the released data/ layout (bound/global SDFs, unpacked) and the AIMNet2-CPCM model file
b973c_cpcm_ens_f.jpt in the working directory. sf_timing.py needs SaddleForge
(https://github.com/isayevlab/saddleforge); cpu_refs.py needs xtb. Results are in data/timing/sunspear/.
