[![License: MIT](https://img.shields.io/badge/code-MIT-blue.svg)](LICENSE)

Data, model interface and analysis code for

> H. Gokcan, O. Isayev. *Efficient and Accurate Ligand Strain Calculations in Solution with the AIMNet2 Neural Network Potential.* J. Chem. Inf. Model. **2026**. [DOI to be added]

Ligand conformational strain energy (LCSE) is the energy a ligand pays to adopt its protein-bound conformation. The usual estimate references a single gas-phase minimum, which collapses charged ligands into compact, intramolecularly hydrogen-bonded conformers and inflates their strain. AIMNet2-CPCM is a neural network potential trained to B97-3c energies and forces in CPCM water that treats neutral and charged species on the same footing, so the unbound reference can be a solvated global minimum found over thousands of conformers per ligand on a GPU.

This repository contains

- **the dataset**: solvated LCSE for 7887 PDB ligands from [LigBoundConf](https://doi.org/10.1021/acs.jcim.0c01197), with the torsion-constrained bound conformer and the solvated global minimum of every ligand, per-ligand descriptors and annotations, and the force-field comparisons from the paper;
- **the model interface**: an ASE calculator for the released AIMNet2-CPCM TorchScript ensemble and a reference implementation of the strain protocol;
- **the analysis code** that produced every figure and table in the paper and its Supporting Information.

Documentation and a browsable summary of the results are at **https://isayevlab.github.io/ligand-strain-aimnet2/**.

## Quick start

```bash
git clone https://github.com/isayevlab/ligand-strain-aimnet2.git
cd ligand-strain-aimnet2
pip install -e .            # numpy, pandas, rdkit, torch, ase
python examples/01_explore_dataset.py
```

```python
from lcse import load_master_table, load_conformers
df = load_master_table()                      # 7887 rows, one per PDB ligand instance
df.lcse_kcal.median()                         # 4.0 kcal/mol
df.groupby("net_charge").lcse_kcal.median()   # strain rises with |net charge|
bound = next(load_conformers("bound"))        # RDKit Mol with AIMNet2-CPCM energy as an SD tag
```

To compute strain for your own ligand you need the model file (see [models/README.md](models/README.md)):

```python
from rdkit import Chem
from lcse import AIMNet2CPCM, ligand_strain
mol = Chem.MolFromMolFile("pose.sdf", removeHs=False)   # bound pose, explicit hydrogens, correct protonation
calc = AIMNet2CPCM(member=0, device="cuda")
res = ligand_strain(mol, calc, n_conformers=300)
print(res["lcse_kcal"])
```

`ligand_strain` relaxes bond lengths and angles of the pose with every rotatable-bond dihedral frozen (bound-state energy), generates ETKDG conformers, optimizes each with AIMNet2-CPCM and takes the lowest (solvated global minimum). Both endpoints are evaluated in CPCM water at the protonation state of the input; see the paper for why this convention is used and where it breaks down (polyanions).

## The dataset in one table

`data/lcse_master_table.csv`, one row per ligand instance (`ligand_id = <code>_<PDB>_<chain>_<resnum>`):

| column | meaning |
|---|---|
| `pdbid`, `ligand_code`, `smiles` | PDB entry, three-letter ligand code, SMILES of the deposited protonation state |
| `net_charge`, `n_heavy`, `n_rotatable`, `aromatic_proportion`, `n_hba`, `n_hbd`, `mol_weight`, `NPR1`, `NPR2` | descriptors (rotatable bonds from Omega; aromatic proportion = aromatic bonds / all bonds) |
| `EC_no`, `enzyme_class`, `enzyme_subclass`, `ligand_function`, `ligand_class` | PDBe annotations of the target and ligand (`ligand_function = cofactor` for the 304 cofactors) |
| `global_pair` | the ligand_id whose global minimum is shared (same chemical species across entries) |
| `n_omega_conformers` | conformers generated by Omega (cap 5000) |
| `E_bound_hartree`, `E_global_hartree` | AIMNet2-CPCM energies (4-member ensemble mean) of the two endpoints |
| `lcse_kcal` | LCSE = E_bound − E_global, kcal/mol |
| `mmff94_strain_sp_kcal`, `mmff94_strain_reopt_kcal` | MMFF94 strain, single point on the AIMNet2-CPCM conformers and after re-optimizing both endpoints on MMFF94 |

Structures: `bound_conformers.sdf.gz` and `global_conformers.sdf.gz` (7887 each, explicit H, SD tags `energy_hartree`, `final_fmax_eV/A`, `model_name`). Atom order differs between the two files for the same ligand; map atoms by substructure match before comparing coordinates (see `scripts/gaff.py`).

## Reproducing the paper

| Result | How |
|---|---|
| Figures 3 to 6, S2, S7 to S13 (distributions by property, EC, multi-target) | `notebooks/LCSE_analysis.ipynb` |
| Figure S14, conformer statistics | `python scripts/confstats.py` |
| Figure S15 and Table S4, MMFF94 single-point and re-optimized strain, all ligands | `python scripts/mmff.py && python scripts/mmff_fig.py` (~20 min CPU) |
| Figure S16 and Table S5, GAFF2 in vacuum and OBC2 on the 50-ligand subset | `python scripts/gaff.py && python scripts/gaff_fig.py` (needs OpenMM stack; ~1 h CPU) |
| Table S3, timings | `scripts/timing/` (GPU scripts need the model and, for the batched rows, [SaddleForge](https://github.com/isayevlab/saddleforge)) |

Scripts read from `data/` and write next to it; set `LCSE_DATA_DIR` to point elsewhere.

## Level of theory and limitations

Reference: B97-3c (B97 GGA, def2-mTZVP, D3(BJ), SRB correction) in CPCM(water, ε = 80), ORCA 5.0.3. The model inherits this reference: conformational energies of flexible charged molecules carry errors of 1 to 2 kcal/mol relative to higher-level treatments, and continuum solvation over-stabilizes compact conformers of polyanions, so LCSE values at net charge −3 and below are upper bounds. Bound-state energies use crystallographic torsions and inherit refinement error. Read the values as distributions and rankings rather than exact per-ligand penalties.
